## 🧠 My Thesis on Agentic AI

**Agents are not just a model problem. They're an infrastructure problem.**

The industry spent decades building the connective tissue of modern software: APIs, identity, gateways, service meshes, event streams, observability, security, and cloud-native platforms.

Now agents are becoming a new kind of consumer of that infrastructure.

The opportunity isn't to throw away everything we built. It's to **evolve it for a world where software can reason, discover capabilities, and take action on behalf of people.**

I think the agentic stack increasingly looks something like this:

```text
              ┌─────────────────────┐
              │       Agents        │
              └──────────┬──────────┘
                         │
              MCP · A2A · Agent APIs
                         │
              ┌──────────▼──────────┐
              │  AI Connectivity    │
              │ Gateways · Routing  │
              │ Identity · Policy   │
              └──────────┬──────────┘
                         │
              APIs · Events · Tools
                         │
              ┌──────────▼──────────┐
              │   Cloud Native      │
              │ Services · Data     │
              │ Infrastructure      │
              └─────────────────────┘
```

The interesting problems are therefore not only about models.

They're about **connectivity, context, identity, security, governance, observability, reliability, and cost**.

And that's where my work is focused.
